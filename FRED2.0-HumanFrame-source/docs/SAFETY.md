# Safety and ethics baseline

## Non-negotiable boundaries

- Always identify the system as a robot; never use emotional deception.
- Obtain informed, revocable consent and respect refusals.
- Minimize collection. Do not record ambient audio or video by default.
- Never infer a diagnosis or alter medication instructions.
- Never promise emergency response. Provide a separate, tested emergency path.
- Human caregivers own care decisions and can review or disable automations.
- Physical motion must have independent collision avoidance and an emergency stop.

## Escalation principle

Clear indications of immediate danger route to an emergency-configured human workflow. Possible distress, confusion, repeated missed check-ins, and uncertain input route to a caregiver. Routine acknowledgements stay local. A real deployment must define contacts, acknowledgement timeouts, retry behavior, regional emergency rules, and what happens during power or network failure.

## Before a supervised pilot

Complete a hazard analysis (including misuse), privacy impact assessment, threat model, clinical review, accessibility testing, incident response plan, and documented informed-consent process. Validate the full notification chain; a successful API response is not proof that help arrived.
